자주 묻는 질문

만드는 데 얼마나 걸리나요?

실속형은 소개 글과 사진을 받은 날부터 2~3주가 걸립니다. 맞춤형은 기능의 크기가 저마다 달라, 상담에서 일정을 함께 정합니다.

글과 사진은 누가 준비하나요?

소개 글과 로고, 사진을 보내 주시면 화면에 맞게 다듬어 넣습니다. 무엇을 준비해야 할지 모르시겠다면, 그것부터 상담에서 함께 정리합니다.

만든 뒤에 직접 고칠 수 있나요?

맞춤형에는 관리자 화면이 있어 공지 · 배너 · 일정을 직접 고칩니다. 실속형은 관리를 맡기시면 대신 고쳐 드리고, 직접 고치고 싶어지면 관리자 화면을 나중에 더할 수 있습니다.

도메인 · 호스팅은 어떻게 하나요?

주소(도메인)가 없으면 함께 고르고, 연결과 보안 인증서까지 맡습니다. 도메인 · 호스팅 이용료는 제작비와 별도로, 드는 만큼만 받습니다.

지금 있는 홈페이지를 고치기만 해도 되나요?

네. 지금 주소를 알려 주시면 먼저 살펴보고, 어디까지 고칠 수 있고 얼마가 드는지부터 말씀드립니다.

결제는 어떻게 하나요?

제작비는 계약할 때 30%, 시안을 정할 때 30%, 공개할 때 40%를 계좌이체로 받고 세금계산서 또는 현금영수증을 발행합니다. 카드 결제는 준비하고 있습니다.

공개한 뒤의 관리를 꼭 맡겨야 하나요?

아니요. 직접 돌보셔도 됩니다. 기본 관리나 운영 대행은 필요해지는 때에 시작하시면 됩니다.

더 궁금한 점은 로 전화하시거나 문의하기로 남겨 주세요.

어떤 홈페이지를 생각하고 계신가요

떠오르는 대로 골라 주시면 한 번 정리해서 연락드립니다. 지금 쓰는 홈페이지가 있다면 주소 하나면 충분합니다.
